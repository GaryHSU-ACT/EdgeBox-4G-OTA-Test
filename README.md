# EdgeBox-4G-OTA-Test
ACT NKUT EdgeBox-ESP-100 4G OTA 遠端韌體更新測試與版本管理

本儲存庫提供 EdgeBox application 韌體及 OTA 更新資訊，原始碼與歷史備份保留於本機。

## 版本更新紀錄

### 2.1.3 — 2026-10-10

- 保存網路設定成功後立即跳轉 `/saved` 結果頁，清楚顯示已保存、等待重啟、已確認重啟與網路連線狀態。
- 使用同一設備的開機識別碼確認重啟；熱點中斷時提供網路切換指引，不直接宣稱更新或連線成功。
- 新增重新確認狀態、返回設定頁及已知設備IP連結；结果資訊可在同瀏覽器重新整理後保留，且不保存密碼。
- 實測電信 `Far EasTone` 顯示為「遠傳電信（Far EasTone）」；4G畫面不再顯示沒有取得的IP欄位。

驗證：官方Edgebox-ESP-100、16MB Flash、Default分區編譯通過，application使用約81% OTA空間。瀏覽器模擬測試涵蓋保存拒絕／成功、結果頁跳轉與重新整理、開機ID確認、Wi-Fi失敗及成功狀態。實機2.1.2已確認4G名稱、Wi-Fi連線及斷電保存；2.1.3新增結果頁仍待實機確認。

### 2.1.2 — 2026-10-10

- 修正Wi-Fi設定保存時，將正常SSID／密碼的結尾NUL誤判為非法內容，導致無法保存的問題；加入编譯期回歸檢查。
- 儲存按鈕立即顯示進度，10秒等待逾時顯示提示，保存成功輸出序列日誌。
- 4G狀態優先要求完整電信名稱，名稱不可用時回退顯示網路代碼；加入原始電信查詢診斷。
- 包含2.1.1的官方板型相容修正：腳位常數改用 `AGRI_PIN_` 前綴，避免與官方 `Edgebox-ESP-100` 板型重複宣告；發布編譯改用官方板型。

驗證：ESP32 core 3.3.11、官方Edgebox-ESP-100、16MB Flash、Default分區、PSRAM Disabled編譯通過，application使用約81% OTA空間；瀏覽器模擬測試通過保存失敗提示、再次提交與正常保存。電信名稱與Wi-Fi保存仍待實機確認。2.1.1僅曾本機編譯，未單獨發布。

### 2.1.0 — 2026-10-10

新增設備內建網路設定頁，支援選擇 4G 或 Wi-Fi 作為對外連線。

- 預設使用 4G，同時開啟 `EdgeBox-xxxxxx` 設定熱點；4G 模式不連接外部 Wi-Fi。
- 可搜尋附近 Wi-Fi、選擇名稱及輸入密碼，也可手動輸入隱藏 SSID。
- 將網路選擇、SSID 與密碼保存至 ESP NVS，下次開機沿用設定。
- Wi-Fi 模式關閉 4G 板上供電；Wi-Fi 取得 IP 後關閉設定熱點。
- Wi-Fi 每次嘗試最多 15 秒，連續三次失敗保留熱點供重新設定；已連線後斷線會重新開啟熱點並重試。
- 設定頁顯示目前網路、連線狀態、電信／Wi-Fi 名稱、訊號強度及四格訊號圖示。
- 4G 訊號以 CSQ 換算 RSSI 估計值，未知訊號不顯示為滿格；Wi-Fi 使用 RSSI。
- 新增 Wi-Fi HTTPS OTA 傳輸及 HTTP Range 續傳，沿用版本、板型、大小與 SHA-256 驗證。
- 網頁服務與 RS485 使用獨立任務，4G 等待及 OTA 期間可查看設定頁；保存設定後等待目前操作完成再重啟。
- 新增序列命令 `a` 手動開啟設定熱點，保留 `c` 檢查更新、`s` 查看狀態。

設定入口：連上設備熱點後，開啟 `http://192.168.4.1`。預設熱點密碼 `EdgeBox2026`；頁面帳號 `admin`、密碼 `EdgeBox2026`。Wi-Fi 成功後，可由同一個 Wi-Fi 網路以設備 IP 開啟設定頁。

驗證：Arduino 編譯通過，application 使用 OTA 分區約 82%；瀏覽器模擬測試通過訊號顯示、Wi-Fi 搜尋選擇及保存流程。實機網路切換、RF、供電及斷線重連仍待現場測試。

### 2.0.0 — 2026-10-10

首支 RS485 與 4G GitHub OTA 整合版。

- UART1 以 9600 baud 讀取氣象站 ID 1、雨雪 ID 2、土壤 ID 11，每 30 秒輪詢。
- 回應檢查地址、長度及 Modbus CRC，讀取失敗重試；完整 CSV 僅在當輪三顆感測器皆有效時輸出。
- UART2 使用 A7670G 4G，探測 115200／460800 baud，檢查 SIM 及電信網路註冊。
- 開機滿 30 秒且網路就緒後檢查 GitHub，之後每 30 分鐘檢查一次；相同或較舊版本不更新。
- 新增 `agri-manifest.txt`，核對板型、檔案大小、SHA-256 與固定 Git commit 的韌體網址。
- 韌體逐塊寫入另一個 OTA 分區，完整驗證後才切換開機目標並重啟。
- 保留 chunk 1024 bytes、間隔 75 ms，加入 chunk 重試及整次下載的 session 恢復次數限制。
- 修正 AT 回應跨等待窗口時半行文字遺失，以及逾時計算減法下溢。

### 1.0.2 — 既有測試版

既有 4G OTA 測試基準：application bin 為 273,904 bytes，使用 `version.txt` 與 `firmware.bin`。本版更新紀錄依先前測試資料整理，不代表重新測試舊韌體。

## OTA 檔案與操作

- `firmware.bin`：編譯後的 application，非 bootloader、分區表或 merged image。
- `version.txt`：版本號，保留供舊測試流程使用。
- `agri-manifest.txt`：目前整合版使用的更新清單，含版本、板型、大小、SHA-256 及固定 commit 下載網址。

首次安裝須接線燒入具 OTA 功能的整合版與正確分區配置。之後設備可自動下載較新版本，或透過 115200 baud 序列監控輸入 `c` 檢查。新版須保留 OTA 功能與相同分區設定。

## 目前限制

這是開發驗證版，尚未配置 OTA CA 憑證驗證、韌體簽章或新版本開機失敗自動回退。SHA-256 驗證檔案完整性，不等於發布者認證。Wi-Fi 設定尚未啟用 Flash 加密；Wi-Fi 未支援 Enterprise 帳號認證或需網頁登入的網路。本韌體只顯示感測器資料，未上傳資料庫。
