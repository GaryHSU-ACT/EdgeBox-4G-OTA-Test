# EdgeBox-4G-OTA-Test
ACT NKUT EdgeBox-ESP-100 4G OTA 遠端韌體更新測試與版本管理

本儲存庫提供 EdgeBox application 韌體及 OTA 更新資訊，原始碼與歷史備份保留於本機。

目前 OTA 最新版：**2.1.24**。設備熱點／本地頁改用 CoGrow 品牌與 DHCP 短名，保留原 Wi-Fi／4G、登入、資料與手動簽章 OTA；發布不代表設備已安裝或實機驗收。

## 版本更新紀錄

### 2.1.24 — 2026-11-07

- 設定熱點改為 `CoGrow-` 加原六碼 MAC 尾碼；Wi-Fi 初始化前設定小寫 `cogrow-` DHCP hostname。這只是本地辨識名稱，不改資料上傳設備 ID，不保證路由器 DNS 或 `.local` 可解析。
- 登入／設定／結果頁使用 CoGrow 品牌。更新或保存結果缺少開機 ID、設備名稱、版本及必要狀態時顯示尚未確認；舊 EdgeBox 熱點名稱不會只因尾碼相同就被視為同設備更新成功。
- 四份來源變動，其餘 44 份逐 byte 保留。原網路／登入帳密、金鑰、CA、端點、感測器清單與 ID、風向校正、補傳格式與簽章 ACK、原 OTA 信任公鑰及分割表保持。沒有加入整合配對 importer、雲端控制／雲端 OTA 或首次設定 helper。
- 本機差異測試、登入與長頁串流、Chrome／Edge 設定與未知結果測試、原 SDK 語法及同設定完整編譯通過；實機 DHCP／AP／資料保留與本輪無線安裝驗收尚待完成。沿用已審查的同一映像，發布時沒有重編。

Application 1,299,568 bytes，SHA-256 `7e4ed61cfa9de8d523d8bf6fbbf7f0cb29449bc44bba2b370048054e7d83479a`。相對 2.1.23 增加 2,064 bytes，原 1,310,720-byte OTA 槽餘 11,152 bytes；靜態 RAM 55,800 bytes 沒有增加，不代表已量測運行 heap／stack。

本次驗收目標為已有有效本地 NVS 登入的 2.1.23，從原設備設定頁手動「檢查更新」再「開始更新」。保留原外部 Wi-Fi，重新啟動後 IP 可能由 DHCP 改派；先用原 IP，必要時由同網段路由器依原 MAC／新 DHCP 名稱查找，再用原帳密登入確認版本。Wi-Fi 成功後熱點仍依原邏輯關閉。若需連熱點，請選新的 CoGrow 名稱，密碼不變。不要清 Flash、設定或待傳資料。

**共用通道影響：** 清單供所有使用此通道的設備讀取，沒有單機隔離。2.1.23 為手動更新；仍運行 2.1.4 等舊自動更新版的設備可能自行嘗試。本版沿既有登入遷移政策，不是任意舊版／空機初始化映像，未驗證從 2.1.4 直接升級的帳密相容性；缺乏有效本地 NVS 時可能無法開啟設定頁。README 不會阻止這些設備下載。恢復舊清單不會使已安裝 2.1.24 自動降版。

## OTA 檔案與操作

- `firmware.bin`：編譯後的 application，非 bootloader、分區表或 merged image。
- `version.txt`：版本號，保留供舊測試流程使用。
- `agri-manifest.txt`：目前整合版使用的更新清單，含版本、板型、大小、SHA-256 及固定 commit 下載網址。
- `agri-manifest.txt.sig`：清單的 ECDSA-P256 簽章，與設備既有信任公鑰核對；缺少／不一致會拒絕更新。

首次安裝須接線燒入具 OTA 功能的整合版與正確分區配置。2.1.5 以上從設定頁先按「檢查更新」，再另按「開始更新」；序列 `c` 也只檢查。新版保留 OTA 與相同分區設定。上方較舊版本的自動 OTA 敘述只代表當時行為。

## 目前限制

這是開發驗證版。OTA 已有 ECDSA-P256 來源簽章及 SHA-256 完整性驗證，尚未配置 OTA TLS CA 驗證或新版本開機失敗自動回退。選用資料上傳另使用設定的 HTTPS CA 與設備 HMAC，與 OTA 通道分開。Wi-Fi 設定尚未啟用 Flash 加密；Wi-Fi 未支援 Enterprise 帳號認證或需網頁登入的網路。網站／資料庫尚未正式接入，上傳預設停用。
